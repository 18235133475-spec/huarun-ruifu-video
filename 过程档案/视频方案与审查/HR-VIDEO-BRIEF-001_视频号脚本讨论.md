# 本轮任务

用户提供《一栋楼，为太原转了个身》主稿，希望根据内容制作微信视频号视频，目前先讨论脚本。原稿及11张内嵌图已保存在[HR-VIDEO-SRC-001](HR-VIDEO-SRC-001_一栋楼为太原转了个身_主稿转写.md)，用户Word原件保持不变。

当前依据是2号楼建筑面积约355㎡。甲方更正与平面见[HR-IMG-007](../项目资料/HR-IMG-007_2号楼355㎡户型图.md)。不再使用早期1号楼或“最后一栋／收官”的口径。2026年10月16日的交接书保留为历史快照，不作为当前楼号与阶段依据。

# 先讨论的叙事选择

编辑建议暂按约3分钟、竖屏组织。建筑线稿分镜初稿的旁白为496个汉字，另外为模型展开、观看与转场保留停顿，最终时长需试读后确定。用户已确认全程旁白，以大模型辅助的三维模型和建筑线稿动画为主要呈现，局部实景仅作论证辅助。时长、竖屏、具体线稿配色和制作工具均仍是编辑建议，未获用户逐项确认。

建议主线为“这栋楼转过身以后，怎样改变一家人的一天”。由楼栋朝向差异进入，解释两侧景观，再让人物在客厅、餐厅和茶区移动，最后说明相聚与独处的安排。文章原有四个理由可重新排序，视频不必按四个章节逐项宣讲。

“一纵一横”继续作为空间段的组织方法。纵线让观看内容随时间和位置变化，横线让相聚和私人起居各有位置。镜头先展示关系，再让旁白点明，不要求观众先记一整套方位口诀。

# 约3分钟的讨论结构

| 时段 | 叙事任务 | 画面建议 |
| --- | --- | --- |
| 0至15秒 | 为什么这两栋朝向不同，及时识别本次2号楼 | 鸟瞰或总平高亮1、2号楼，画出朝向差异，随后锁定2号楼 |
| 15至40秒 | 转过身之后的两侧，突出和园与城河 | 地理关系图配区域日夜景，湖、山、天际线按条件作为补充 |
| 40至55秒 | 进入355㎡所在单元，建立回家的私密尺度 | 一层一户、两梯一户的单元示意，清楚保留另一单元存在 |
| 55至115秒 | 纵线作为主体，下午客厅、晚餐、入夜茶区 | 在2号楼平面或白模中沿客餐茶移动，场景时间随之变化 |
| 115至135秒 | 同窗不同观看位置的体验 | 窗前站立与沙发坐下作对照；楼层变化可用短示意补充 |
| 135至165秒 | 横线解释家人相聚与私人生活 | 东侧公共生活与西侧主人起居分色，表现聚与独处的转换 |
| 165至180秒 | 回到城市与家，收束“转身”的意义 | 从户内退回楼栋与城市远景，落项目名和原题 |

时间是讨论用分配，尚非逐镜头锁定时间。后续按实际口播、素材和用户偏好调整。

# 内容取舍建议

- 保留“转身”、两侧景观、客餐茶的时间变化、窗前与厅内的观看、东侧相聚与西侧私人起居。它们都能用可见动作和图解推进。
- 麦田到文化岛提供时间厚度，可以一句或一个短镜头轻带。夏邦杰生平、去世和场馆交付另起人物线，本片暂不展开。
- 规划变化及样板间投入属于另一组论据，需要数据口径与来源解释。本条视频建议将主体时长留给居住体验，品牌可由具体空间安排体现；若用户坚持保留，再重分时长。
- “天花板”“再往上没有了”等评价暂不作为开场与结尾的中心，把观看兴趣留在这栋楼究竟有什么不同。此为视频编辑建议，并非对主稿的整体改写要求。
- 355㎡所在单元一层一户、两梯一户，不写成整栋只有一户一层；不由梯户比推导电梯必然不用等或没有访客。

# 画面与依据

原稿中的鸟瞰、区位图和2号楼户型分析图可用作镜头讨论参考；配图实际清晰度和授权由制作阶段确认。图中文字适合文章阅读，视频需要拆开呈现，不能整页缩小后直接当作有效说明。

2号楼与1号楼东西镜像，2号楼是东侧聚、西侧私。独立`立体户型模型/`保存的是早期1号楼模型，不能直接改标签当作2号楼。`视频/anatomy/ruifu-2/`已有镜像后的2号楼白模测试素材，但其中树、河、城市的摆放仍是概念，不等于实测区位或窗前视野。

楼栋朝向用总平高亮和两条朝向线说明，不做仿真楼体真的旋转的画面，以免误解成某次规划变更才改变朝向。日夜、窗前与沙发、不同高度的画面，在没有对应房源实拍时要明确其示意身份。

视频目录中已有讲解版、白模版和两份旁白，是此前的测试素材，本轮尚未被用户确认采用。此轮只讨论脚本，没有重新生成视频或发布。

# 已向用户询问

1. 呈现方式倾向真人出镜穿插画面、全旁白，还是先由编辑建议。
2. 实际可用素材包括哪些航拍、2号楼实拍、样板间、宣传片或静态图片。

用户已回复两项问题，明确全程旁白、三维建筑线稿动画主导、实景仅为辅助。接下来按同一模型中的三个连续段落组织镜头，先从城市进入这一户，再沿公共区走过一天，最后展开相聚与私人起居。[动画分镜初稿](HR-VIDEO-SCRIPT-001_建筑线稿动画分镜初稿.md)已据此展开，尚未被用户批准。
