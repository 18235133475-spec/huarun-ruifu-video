# 全片改造计划与镜头对照表

## 一、改什么，不改什么

- **改画面：** 全片只用一套自绘体系，即风格样帧第三版的画法。v1 里的即梦视频、甲方效果图、文章原图推镜全部撤下。甲方效果图只作立面和位置参考。看完 v2 成片后，再决定要不要在个别位置加写实图。
- **不改配音和结构：** 镜号、配音稿、配音音频沿用 v1（HR-VIDEO-002），全片约 4 分 40 秒。画面按配音卡点。
- **即梦积分：** 本版不用。

## 二、三套规则

### 画法（6 种，同一色板）

| 代号 | 画法 | 样帧 |
| --- | --- | --- |
| 日 | 区域底图·白天：米白底、扁平轴测、园绿、水蓝、城灰，1、2号楼赤陶 | 第三版 01 |
| 夜 | 区域底图·夜景：同一张图换暗底，窗灯和道路亮起 | 第三版 04 |
| 旧 | 区域底图·旧貌：同一张图退回田地，汾河收窄（2002 年影像为依据） | 新做 |
| 楼 | 楼栋近景：立面按效果图特征画（白楼板线、灰蓝玻璃、金冠顶） | 第三版 03 |
| 户 | 立体户型：剖切模型、软装、剪影小人；讲到哪推近哪，其余褪色，交通核始终弱化 | 第三版 02 |
| 纸 | 纸面：金句卡、数据卡、线描，与底图同底色 | 新做 |

### 转场（5 种）

| 代号 | 转场 | 用法 |
| --- | --- | --- |
| 长 | 同图生长 | 不切画面，在同一张底图上加信息或减信息（楼长出来、水流进来、标签出现） |
| 移 | 镜头连续运动 | 推拉摇移，从一处滑到另一处 |
| 剪 | 剪纸斑块 | 同一机位换状态：日→夜、旧貌→今天、线稿→上色 |
| 转 | 转身（本片专属） | 画面以 1、2号楼为轴整体转约 37° 切到下一镜。只在章节交接处用，全片 5 次 |
| 纸 | 纸面滑入 | 纸面镜头从底图上层滑入或抽走 |

### 标题排法（5 种，按构图选，不固定位置）

| 代号 | 排法 | 用在 |
| --- | --- | --- |
| 竖 | 竖排大字，放在底图留白一侧 | 区域底图上的章节开篇 |
| 下 | 左下横排大字 | 户型整户画面 |
| 右 | 右上右对齐 | 楼栋近景、天空留白处 |
| 中 | 居中对称 | 片名、金句、结尾 |
| 注 | 不出大标题，只用跟着物体走的场景标注 | 其余大多数镜头 |

**约束：**
- 每章只在开篇出一次大标题。
- 推近讲细节时，大标题退场，左上留一个章节小标签。
- 字幕全片统一在底部居中。

## 四、制作步骤

每完成一步就发给你看，你确认后再做下一步。

1. **工程整理（不出画面）**
   - 把样帧代码拆成公共模块：色板与字体、区域底图（日、夜、旧貌）、立体户型、纸面、转场。
   - 剪纸转场改成在 Remotion 里实时合成，这样运动镜头之间也能用。目前是先渲成静帧，再用 Python 处理。
2. **开场 A1–A6**
   - 发开场粗片：画面完整，配音和音乐都在。
3. **第一章 B1–B11**
   - 新做：旧貌底图、西山地形、平台剖面、楼层视线。
4. **第二、三章 C1–D7**
   - 新做：楼板分单元、尺寸线、横线和四分区、主人区路线。
   - 补画背影和走路姿态的剪影小人。
5. **第四、五章 E1–F3，以及全片合成**
   - 音量统一。
   - 每 8 秒抽一帧，整片检查一遍。
   - 发 v2 成片。

## 五、拍板结果（用户2026-10-22确认，均按建议）

- 配音保留“2号楼”，画面说到时 2 号楼单独加亮；不放夏邦杰肖像；本版继续用 AI 配音；时长约 4 分 40 秒。

### 原拍板项

1. **“2号楼”的说法：** 配音里 A5、B10、C1 说的是“2号楼”，画面上 1、2号楼是一组。
   - 我的建议：配音保留文章原句；画面先亮一组，说到“2号楼”时 2 号楼再单独加亮。
   - 另一种做法是改成“1号、2号楼”，但需要先确认 1 号楼也是“独占一个单元”。
2. **夏邦杰肖像（B8）：** v1 用的是即梦生成的线描肖像，画的是真实人物。
   - 我的建议：不放肖像，改用名字卡加上海大剧院线描。
3. **配音：** 本版继续用 AI 配音（时长不变，画面按它卡点）。真人配音放到画面定稿后再换。
4. **时长：** 维持约 4 分 40 秒，不删句子。
