# 户型段小人与软装模型

## 0. 先读这一段

户型段改成了“固定机位、上帝视角”的讲法。每个区域里要放几个小人和少量软装，让画面有生活感：沙发上一家人、圆桌边家宴、茶桌边两个人等。

风格是**建筑模型里那种比例小人**：形体简洁，不要卡通大头，不要写实人脸。导演会统一染成奶白和浅暖色，所以模型自带的颜色和贴图不重要。

## 1. 工作边界

- **只写：** `视频/素材/13_小人与软装/`，以及在 `视频/素材/登记表.csv` 末尾追加的行（备注写“TASK-005”）。
- **规矩照旧：**
  - 不登录、不付费；
  - 遇到人机验证就跳过；
  - cookie 只点“仅必要”；
  - 不用会上传文件的第三方工具；
  - 需要装 Python 包，只能装在 `视频/素材/13_小人与软装/.venv`。

## 2. 要找的东西

**许可只收 CC0。** 优先来源：
- Kenney（kenney.nl）：全站 CC0；
- Quaternius（quaternius.com）：CC0；
- Poly Pizza（poly.pizza）：只收标注 CC0 的条目，其他许可一律不要。

| 类别 | 数量 | 要求 |
| --- | --- | --- |
| 坐姿成人 | 4 | 能放在沙发、餐椅上；男女都要 |
| 站姿成人 | 3 | 自然站立，有一个在打电话或拿东西更好 |
| 行走成人 | 2 | 用在入户镜头，从电梯走进玄关 |
| 儿童 | 2 | 坐、站各一 |
| 老人 | 1 | 坐姿 |
| 盆栽绿植 | 3 | 落地大盆栽和桌面小盆栽 |
| 落地灯、台灯 | 2 | — |
| 地毯 | 2 | 简单平板即可 |

**规格：**
- **格式：** glTF/GLB 优先，其次 FBX、OBJ。拿到 FBX 或 OBJ 的，用 Blender 命令行转成 GLB，原件也保留；没有 Blender 就保留原格式，在汇报里写明。
- **面数：** 每个模型不超过5000个三角面。
- **比例：** 成人身高按1.65–1.80米检查。不对的不要改原件，在登记表备注里写实际高度。
- **姿态：** 带骨骼动画的，只要静态姿态也可以。行走的如果有动画，一并保留。

**审美：** 把所有候选并排渲染一张对比图（白色材质、统一灯光，可以用 Blender 或 Python 渲），存为 `13_小人与软装/对比.png`。整组放在一起要协调：同一种简化程度、比例一致。有明显卡通或写实的，换掉。

## 3. 登记与汇报

- **登记表：** 每个模型一行，追加到 `登记表.csv`。许可写“CC0”，来源写到具体页面。
- **汇报：** 写 `13_小人与软装/汇报.md`，三段：
  1. 收了什么（逐项清单）；
  2. 推荐哪几个用在哪个场景：入户、客厅、餐厅、茶区、主人套房；
  3. 问题。
