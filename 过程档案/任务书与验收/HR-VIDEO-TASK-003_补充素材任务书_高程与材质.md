## 2. 高程数据

**用途：** 动画开场的暗色三维地形，西山、汾河谷地要有起伏。三维建模 Agent 会用它生成地形高度图。

**来源：** AWS 开放高程瓦片（Terrarium 格式，公开下载，无需登录）：

```text
https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png
```

**步骤：**

1. **定外框。** 打开 https://nominatim.openstreetmap.org ，搜索“山西大剧院”（搜不到就试“Shanxi Grand Theatre”），记下经纬度。以它为中心：
   - 向北、向南各扩 0.05°；
   - 向东扩 0.06°；
   - 向西扩 0.20°，把西山包进来。

   得到南、西、北、东四个数字，写进汇报。
2. **换算瓦片编号。** 对缩放级别 z = 12 和 z = 13，分别算出外框四个角所在的瓦片编号，然后下载这个范围内的全部瓦片：

   ```text
   x = floor((经度 + 180) / 360 × 2^z)
   y = floor((1 − ln(tan(纬度) + 1 / cos(纬度)) / π) / 2 × 2^z)    （纬度用弧度）
   ```

   注意：北边的纬度大，算出来的 y 小；南边的 y 大。
3. **保存。** 原样保存为 `10_高程数据/z12/x_y.png` 和 `10_高程数据/z13/x_y.png`。同时写一个 `10_高程数据/tiles.json`，记录外框四至、每个缩放级别的 x、y 范围和瓦片总数。
4. **自查。**
   - 每张瓦片都是 256×256 的 PNG，没有下载失败的空文件。
   - 用 Python 把 z=12 的瓦片按编号拼成一张图，换算成灰度（海拔 = R × 256 + G + B / 256 − 32768），存为 `10_高程数据/preview_z12.png`。打开看一眼：西边应该是较亮的山地，中间偏东有一条较暗的南北向河谷（汾河）。如果看不出来，说明外框或编号算错了，返回第1步检查。

## 3. 材质与光照贴图

**用途：** 户内镜头里，白模逐渐“长出”木地板、石材、布艺。风格参照参考视频 `视频/参考视频/参考2_镜头穿梭.mp4` 的0:12–0:15，先看一遍这一段。

**来源：** 只用 CC0 资源，无需登录即可下载：
- Poly Haven：https://polyhaven.com （材质在 Textures，环境光照在 HDRIs）
- ambientCG：https://ambientcg.com

**要找：**

| 类别 | 数量 | 要求 |
| --- | --- | --- |
| 浅色木地板 | 3 | 浅橡木、浅白蜡木一类，纹理细，不要深色、不要做旧 |
| 浅色石材 | 3 | 米白大理石、浅灰石材，纹理克制，不要大面积黑色纹路 |
| 布艺 | 3 | 米色、燕麦色的亚麻或绒布 |
| 墙面 | 2 | 白色或米白的细腻涂料、微水泥 |
| 室内环境光照 HDRI | 3 | 白天柔光、傍晚暖光、夜晚各一张 |
| 室外环境光照 HDRI | 2 | 晴天、多云各一张，用于城市场景 |

**规格：**
- 材质下载 2K 分辨率，只要三张图：颜色（Diffuse 或 Color）、法线（Normal，选 OpenGL 版本）、粗糙度（Roughness）。
- HDRI 下载 2K 的 .hdr 文件。

**审美标准：** 整体是参考2那种奶白、浅木、浅灰的温和色调。拿不准时，把候选图并排放在一起看：整组放在一起应该显得干净、明亮、协调。有任何一张显得突兀，就换掉。

**每类保存一张对比图：** 用 Python 把同一类的候选颜色图缩成 512×512 横排拼在一起，存为 `11_材质与光照/<类别>_对比.png`。
