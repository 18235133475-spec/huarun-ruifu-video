## 3. B1：高程数据

**用途：** 动画开场的暗色三维地形，要看得出西山和汾河谷地的起伏。三维建模 Agent 会用它生成地形高度图。

**来源：** AWS 开放高程瓦片（Terrarium 格式，公开下载，无需登录）：

```text
https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png
```

**外框已经算好，直接用：** 以山西大剧院（37.807091, 112.5271115）为中心，北、南各扩0.05°，东扩0.06°，西扩0.20°（把西山包进来）：

```text
南 37.7571   西 112.3271   北 37.8571   东 112.5871
```

**瓦片编号也已经算好，用来核对：**

| 缩放级别 | x 范围 | y 范围 | 瓦片数 |
| --- | --- | --- | --- |
| z=12 | 3326–3328 | 1582–1583 | 6 |
| z=13 | 6652–6657 | 3164–3166 | 18 |

**步骤：**
1. **算编号。** 用下面的公式自己算一遍，结果要和上表一致；不一致就停下检查，不要下载。

   ```text
   x = floor((经度 + 180) / 360 × 2^z)
   y = floor((1 − ln(tan(纬度) + 1 / cos(纬度)) / π) / 2 × 2^z)    （纬度用弧度；北边 y 小，南边 y 大）
   ```

2. **下载。** 原样保存为 `10_高程数据/z12/x_y.png` 和 `10_高程数据/z13/x_y.png`。
3. **记录。** 写一个 `10_高程数据/tiles.json`，内容包括：外框四至、每个缩放级别的 x 和 y 范围、瓦片数、来源地址、下载日期、换算公式。换算公式为：海拔 = R × 256 + G + B / 256 − 32768。
4. **自查。**
   - 一共24张，每张都是256×256的 PNG，没有空文件。
   - 用 Python 把 z=12 的6张按编号拼成一张图，按上面的公式换算成灰度，另存为 `10_高程数据/preview_z12.png`。
   - 打开看一眼：西边应该是较亮的山地，中间偏东有一条较暗的南北向河谷（汾河）。看不出来，说明编号算错了，回到第1步。

## 4. B2：材质与光照贴图

**用途：** 户内镜头里，白模逐渐“长出”木地板、石材、布艺。先看参考视频 `视频/参考视频/参考2_镜头穿梭.mp4` 的0:12–0:15，色调照这段找。

**来源：** 只用 CC0 资源，无需登录即可下载：
- Poly Haven：https://polyhaven.com （材质在 Textures 栏目，环境光照在 HDRIs 栏目）
- ambientCG：https://ambientcg.com

**要找：**

| 类别 | 数量 | 要求 |
| --- | --- | --- |
| 浅色木地板 | 3 | 浅橡木、浅白蜡木一类，纹理细；不要深色，不要做旧 |
| 浅色石材 | 3 | 米白大理石、浅灰石材，纹理克制，不要大面积黑色纹路 |
| 布艺 | 3 | 米色、燕麦色的亚麻或绒布 |
| 墙面 | 2 | 白色或米白的细腻涂料、微水泥 |
| 室内环境光照 HDRI | 3 | 白天柔光、傍晚暖光、夜晚各一张 |
| 室外环境光照 HDRI | 2 | 晴天、多云各一张，用于城市场景 |

**规格：**
- 材质下载2K分辨率，每套只要三张图：颜色（Diffuse 或 Color）、法线（Normal，选 OpenGL 版本）、粗糙度（Roughness）。
- HDRI 下载2K的 .hdr 文件。

**审美标准：** 整体是参考2那种奶白、浅木、浅灰的温和色调。拿不准时，把同类候选并排放在一起看：整组应该干净、明亮、协调，有任何一张显得突兀就换掉。

**对比图：** 每类做一张。用 Python 把同类的颜色图缩成512×512，横排拼在一起，存为 `11_材质与光照/<类别>_对比.png`。

**命名：** 格式为 `类别_名称_分辨率_贴图类型.扩展名`，全部用英文小写，例如：

```text
11_材质与光照/wood_light_oak_2k_color.jpg
11_材质与光照/wood_light_oak_2k_normal.png
11_材质与光照/wood_light_oak_2k_roughness.jpg
11_材质与光照/hdri_indoor_day_2k.hdr
```
