# 开场行车镜头精细化试点任务书

## 0. 一句话目标

开场行车镜头（O1，约 0:04–0:13）沿滨河西路往南开：右手边是瑞府楼栋，左手边是滨河绿带和汾河。现在这一带的近景“看着像白模”。

本任务把这一带做成**精细但不写实**的三维模型。要求是：
- 形体、层次、细部清楚；
- 扁平纯色、无贴图；
- 风格和全片现有的插画式画面一致。

这是试点。做得好，再推广到其他近景和半鸟瞰镜头。

## 1. 边界与纪律（必须遵守）

1. **只写一个目录**：`视频/模型/pilot_o1/`（新建）。其他文件一律只读，包括 `视频/模型/` 下已验收的文件、`视频/动画工程/`、`视频/甲方提资/`、`视频/素材/`。
2. **不联网下载、不登录、不上传**任何本地文件。甲方资料只在本机读。所需数据都已在本地，见第 3 节。
3. Python 依赖装在 `视频/模型/.venv`，不改系统环境。沿用 `视频/模型/源文件/gltf_writer.py` 的写法，不要求 Blender。
4. 坐标系与已有模型一致：
   - 单位米；x 向东、y 向上、z 向南。
   - 原点在山西大剧院形心（UTM 49N，E0=634430.0964288089，N0=4185498.7249752167）。
   - 顶点直接在场景坐标里，导入后不用平移。
5. **风格**：
   - 不要贴图、不要照片纹理、不要写实的脏旧、不要随机噪点。
   - 细节要靠几何体现：挑檐、栏板、竖向线条、退台、檐口、雨棚、路缘石、灯杆。
   - 颜色只用第 4 节的色板。
6. **分节点交付**：
   - 先做第 6 节的“节点 1”，做完**停下汇报**，等验收意见再继续。
   - 不要一次做完全部。

## 5. 要做什么

### 5.1 瑞府楼栋（重点）

**节点结构**
- 每栋一个父节点，名字和 `ruifu.glb` 完全一致（`ruifu_b01`…`ruifu_b23`、`ruifu_t1`…`ruifu_t3`）。
- 父节点原点、translation、rotation 的约定也和 `ruifu.glb` 完全相同，见 `说明.md` 第“层数、角度与动画”节。
- 1、2号楼在片中会从正南转到西南，所以几何必须按“正南正北展开”，转角只放在父节点 rotation 上。

**高度修正表**（以总平面标注为准，其余按 `ruifu_meta.json`，层高 3m）

| 楼 | 层数 | 高度 |
|---|---|---|
| T1 | 30F | 120.75m |
| T2 | 35F | 140.25m |
| T3 | 24F | 96.75m |
| 13#、14# | 24F | 97.95m |
| 23# | 20F | 70.75m |

**住宅立面**（照甲方效果图的特征，简化表达）
- **楼板**：每层一道白色楼板挑檐，外挑约 0.3m，厚约 0.3m。
- **玻璃**：玻璃面整体退在楼板内侧约 0.4m。
- **阳台**：沿南北长边设通长玻璃栏板，高 1.1m。
- **金线**：四个转角各一条香槟金竖线，从地面通到冠顶。
- **冠顶**：顶部约 2 层（6.5m）是金色竖向格栅，间距约 1.3m，加一圈出挑薄屋檐。
- **首层**：入口大堂约 6m 高，做成石材加玻璃，主入口有雨棚；位置放在北侧长边中部。
- **屋顶**：设备围挡加几块设备体块。
- **可选**：单元之间可做一条深色竖向凹槽。

**写字楼立面**（T1–T3、13、14、23）
- **竖梃**：间距 1.5m，凸出约 0.15m。
- **层间横带**：每 4.2m 一道。
- **首层**：首层或裙房做通高玻璃，加雨棚。
- **屋顶**：女儿墙加设备。

**面数**：住宅每栋 ≤ 40,000 三角面，写字楼每栋 ≤ 30,000，全部楼栋合计 ≤ 1,000,000。

### 5.2 滨河西路（行车镜头的地面主角）

**横断面**（主路两幅加中分带，宽度以 OSM 两条中线间距为准，不足处按常规补齐）：
- 每幅 3–4 条车道，路面 `asphalt`，高 0.1m。
- 两侧路缘石 `curb`，高 0.15m。
- 中分带宽约 3m，抬高 0.2m，`median_green`，带低矮灌木团（简单几何即可）。
- 外侧人行道宽 3–4m，`sidewalk`，与非机动车道之间有绿化带。

**路灯**
- 双臂高杆路灯，每 30m 一根，放在中分带上。
- 杆 `lamp`，高约 11m；灯头 `light`。

**车道线**：不用做，动画端已有。

### 5.3 滨河绿带（滨河西路东侧到汾河水边）
- 沿河一条主步道（宽约 4m，`path`），一条蜿蜒的次步道。
- 水边一道驳岸台阶或矮挡墙（`water_edge`），加滨水栏杆（`rail`，高 1.1m）。
- 小品：每 40–60m 一组座椅，每 25m 一盏庭院灯（高 4m）。
- 树只出**实例清单** `trees_o1.json`：
  - 格式参照和园 `trees.json`：[x, z, 树冠直径, 高度, 树种索引]。
  - 树种用和园树原型的索引。
  - 行道树沿人行道每 8m 一棵，绿带里成丛自然分布。
  - 不要压在步道和路面上。
