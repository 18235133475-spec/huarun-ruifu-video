# 全片模型精细化任务书

## 0. 一句话目标

成片的镜头、时长、字幕、配音**全部锁定，一帧不改**。本任务只做一件事：把成片里出现的三维模型，从“干净但粗糙”提升到“干净、精细、经得起近看”。

风格和以前一样：**精细但不写实**。
- 扁平纯色，不用贴图。
- 细节靠几何表达：挑檐、栏板、线脚、退台、门窗框、家具构件等。

验收方会在你全部做完后，统一接入动画工程、统一验收、统一渲染。所以你**不碰动画工程**，只交模型和数据。

## 1. 执行方式（请先读完这一节）

1. **一次性跑完，中途不停下等人。** 按第 6 节的顺序做完全部任务包 A→G。每个包做完先跑自检（第 8 节），再进下一个包。
2. **遇到拿不准的事，不要停。** 按本文件的规则选最保守的做法继续，把决定写进 `决定记录.md`：一行一条，写清是什么问题、怎么定的、为什么。
3. **可断点续跑。**
   - 每完成一个包，更新 `进度.md`：哪些包已完成，自检是否通过，下一步做什么。
   - 中断后重新开始，先读 `进度.md`，从断点继续，不要重做已通过的包。
4. **按优先级保证质量。**
   - 如果时间或资源只够做一部分，**先把 P0 包做到验收标准**，再做 P1、P2。
   - 宁可少做一个包，也不要每个包都做一半。
5. **全部做完后**，写 `汇报.md`（格式见第 9 节），然后结束。

## 5. 通用交付规格

1. **格式**：glTF 2.0 二进制（`.glb`）。
   - 材质是 `pbrMetallicRoughness` 纯色：metallic 0，roughness 0.9。
   - 不带贴图、图片、采样器。
   - 法线正确，没有退化三角形，没有重叠共面（z-fighting）。
2. **节点**：每个“可单独控制的东西”一个父节点，节点名见各包。
3. **重复小件用实例**：原型放在 `<包>_protos.glb` 里，一个原型一个节点；实例清单写成 JSON：
   ```
   [[原型名, x, y, z, 绕y旋转弧度, 统一缩放], ...]
   ```
4. **树**：只出实例 JSON，格式同 `动画工程/public/v2/heyuan/trees.json`：
   ```
   [x, z, 树冠直径, 高度, 树种索引]
   ```
   - 树种索引用和园树原型 `heyuan_tree_prototypes.glb` 的顺序。
   - 不要压在路面、铺装、建筑足印上。
5. **面数上限**：见各包；全部包合计 ≤ 4,000,000 三角面。
   - 远看看不见的细节不要做，例如被遮挡的内侧面、屋顶设备的背面。
   - 面数花在镜头里看得见的地方。
6. **每个包一个子目录**：`refine_v1/<包号>_<名称>/`，内含：
   - `.glb` 文件；
   - 实例 JSON；
   - `meta.json`（面数、材质清单、范围、自检数据、所有估计值的说明）；
   - `compare_*.jpg` 对照图。

**住宅规则**（b01–b12、b15–b22）：
1. **楼板与玻璃**：
   - 每层白楼板挑檐，厚 0.45m；长边外挑 0.4m，端头 0.25m。
   - 楼板之间是通长深色玻璃，退在楼板内 0.4m。
   - 阳台玻璃栏板高 1.1m，外皮贴楼板外沿。
2. **竖向元素**：
   - 单元分界处一条深色竖向凹槽，宽 1.8m、退进 0.5m。凹入面用 `glass`，两侧侧壁用 `rail_glass`。
   - 分界位置取 `ruifu_meta.json` 里各楼 `window_segments` 段间空隙的中点。没有该数据的楼，按长边三等分。
   - 四角各一条香槟金竖线。
3. **冠顶**：
   - 顶部 6.5m 是金色竖格栅：片宽 0.3m、深 0.9m、中距 1.3m。
   - 格栅后面是退进 1.5m 的白色体量。
   - 最上面一圈 0.4m 厚的白薄檐，收回到足印线。
4. **首层**：
   - 6m 高的石材加玻璃大堂，放在北侧长边中部。

5. **屋顶**：设备藏在冠顶白色体量后面，不可见的不做。
6. **1、2号楼**：

| 户型 | 墙体中线与 `unit_plan.json` 偏差 ≤ 0.05m；家具与 `unitdress.ts` 现布置的位置偏差 ≤ 0.1m、转角一致 |
| 材质 | 只用第 4 节材质名，色值一致；无贴图、图片、采样器 |
| 面数 | 不超过各包上限 |
| 校验器 | Khronos glTF Validator 0 错误 |
| 几何质量 | 无退化三角形；无共面重叠（共面层之间至少错开 0.01m）；法线朝外 |
| 实例 | 实例不压路面、铺装、足印（逐个检测，输出冲突数 = 0） |
| 对照图 | 每包按第 7 节列出的机位出“左旧右新”对照图 |

**如果你的环境不能看图**：用像素统计做定量验证，像上一轮那样。比如：
- 白、深横线的条带数；
- 格栅区金色与白色的像素比例；
- 楼栋在画面中的位置和是否被遮挡。

结果写进 `meta.json`。

## 10. 验收方会怎么验

全部包交回后，验收方会做这些：
1. **复核**：重跑第 8 节的全部自检。
2. **接入成片**：
   - 按材质名、节点名接入动画工程；
   - 在 v9 的每一个相关镜头里，用成片的真实机位、光照和夜景着色器渲染。
3. **逐镜头对比**：新旧对比，重点看四点：
   - 风格是否和全片一致：干净、扁平、精细，不写实、不花；
   - 近景是否经得起看：楼栋立面层次、园林、软装是否“讲得出片中在讲的事”；
   - 有没有穿模、闪烁、漂浮、遮挡关键内容；
   - 户型软装是否和片中人物、动线、视线扇形对得上。
4. **出结果**：验收通过后统一渲染全片。不通过的包会出返工意见，只返工那一个包。
