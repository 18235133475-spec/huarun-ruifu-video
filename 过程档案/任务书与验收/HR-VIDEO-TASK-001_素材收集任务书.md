# 《一栋楼，为太原转了个身》动画素材收集任务书

## 0. 先读这一段

你要为一条约2分50秒的建筑科普动画收集素材。三维建模由另一位 Agent 按 `视频/任务书/HR-VIDEO-TASK-002_三维建模任务书.md` 来做，它会用到你收集的地理数据、高程数据和地标参考，所以**第3.1、3.8、3.2节是最重要的交付**。你**只负责找、下载、整理和登记素材**，不做设计，不修图，不剪辑。音乐、音效和配音另行生成，不需要你找。

分镜脚本在 `视频/脚本/HR-VIDEO-001_一栋楼为太原转了个身_分镜脚本.md`。开始前请通读一遍，知道每样素材用在哪个镜头。

**判断一样东西要不要，只看三点：**
1. 来源清楚，能写出网址。
2. 授权清楚，能写出许可类型。
3. 质量达到本任务书写明的规格。

三点有一点做不到，就不要，或者放进“仅参考”目录并在登记表里写明原因。**宁可少，不要乱。**

## 3. 收集清单

### 3.1 地理数据（最重要，决定三维场景准不准）

**用途：** 镜1、镜4到16、镜23、24的三维城市底盘：汾河、内河、文化岛、五大馆的位置、长风商务区楼群、和园、谐园、道路。

**来源：** OpenStreetMap（开放数据，许可 ODbL，可以商用，成片需署名“© OpenStreetMap contributors”）。

**步骤：**
1. **定范围。** 打开 https://nominatim.openstreetmap.org ，分别搜索“山西大剧院”和“太原 华润瑞府”（搜不到就试“太原瑞府”“Shanxi Grand Theatre”）。记下两处的经纬度。
2. **取外框。** 以两点连线的中点为中心，向北、向南各扩 0.025°，向东、向西各扩 0.03°。这个外框必须同时包含山西大剧院、瑞府地块、汾河两岸和南中环街；包含不全就继续扩大。把最终的南、西、北、东四个数字写进汇报。
3. **导出数据。** 打开 https://overpass-turbo.eu ，粘贴下面的查询，把 `S,W,N,E` 替换成上一步的四个数字（顺序是南纬度、西经度、北纬度、东经度），运行后选“导出 → GeoJSON”下载。

```text
[out:json][timeout:180];
(
  way["building"](S,W,N,E);
  relation["building"](S,W,N,E);
  way["waterway"](S,W,N,E);
  way["natural"="water"](S,W,N,E);
  relation["natural"="water"](S,W,N,E);
  way["leisure"="park"](S,W,N,E);
  relation["leisure"="park"](S,W,N,E);
  way["highway"](S,W,N,E);
  way["landuse"](S,W,N,E);
  way["bridge"](S,W,N,E);
);
out body;
>;
out skel qt;
```

4. **分图层再导一次。** 为方便建模，再分别只保留其中一类各导一份：建筑、水系（waterway 和 natural=water）、公园、道路。文件分别命名为 `01_长风_建筑轮廓.geojson`、`01_长风_水系.geojson`、`01_长风_公园.geojson`、`01_长风_道路.geojson`，全量的那份叫 `01_长风_全量.geojson`。
5. **检查并记录。** 在 overpass-turbo 的地图上逐项确认，结果写进汇报：
   - 汾河、文化岛外圈的内河有没有画出来；
   - 五大馆五座建筑有没有轮廓，名字标签各是什么；
   - 和园、谐园有没有公园边界，名字标签是什么；
   - 瑞府地块里的住宅楼有没有轮廓，大约多少栋；
   - 建筑有没有 `height` 或 `building:levels` 标签，大约占多少比例。
6. **截图。** 在 overpass-turbo 上把整个外框截一张全图，存为 `01_长风_范围截图.png`。

### 3.2 地标参考（三维体块建模用）

**用途：** 镜8到10、镜14、镜23的五大馆白模，镜3的上海大剧院线稿。

**对象：** 山西大剧院、山西省图书馆、太原美术馆、山西省科技馆、太原市博物馆、上海大剧院。名称以官方为准；如果官方名称和这里不同，按官方名称建目录，并在汇报里说明。

**每座建筑收集：**

| 内容 | 数量 | 要求 |
| --- | --- | --- |
| 俯视或高空航拍 | 1–2张 | 能看清屋顶轮廓和建筑整体形状 |
| 正立面 | 1–2张 | 尽量正对建筑，透视变形小，不要广角大畸变 |
| 侧立面或45°角 | 1–2张 | 能看出体块的前后关系 |
| 关键数据 | 1份文字 | 建筑高度、层数、占地或建筑面积、设计单位、建成或开放年份，每个数字都附出处网址 |

**图片规格：** 长边不小于1600像素；无水印、无大面积文字叠加；白天、晴天或多云，光线均匀，优先选人少、车少的画面。

**优先来源：**
1. 设计单位官网的项目页（例如 Arte Charpentier 的山西大剧院项目页 https://www.arte-charpentier.com/fr/projets/opera-du-shanxi-taiyuan-chine/ ）。
2. 场馆官网、政府网站。
3. Wikimedia Commons（ https://commons.wikimedia.org ，搜英文名或中文名），只要许可是 CC0、CC BY、CC BY-SA 的，登记作者和许可。

**不要：** 图片站带水印的图、自媒体文章里的截图、无法追溯原作者的图。这类图如果构图特别有参考价值，可以放进 `99_仅参考_不可用于成片/`，登记原因。

**这些图只给建模当参考，不直接出现在成片里。** 所以构图清楚、透视正比画面好看更重要。

### 3.3 人物参考（镜2线描肖像用）

**对象：** 让-马里·夏邦杰（Jean-Marie Charpentier），Arte Charpentier 事务所创始人。

**收集：**

- 生卒年份和主要作品的官方出处。已知的出处是事务所纪念页 https://www.arte-charpentier.com/fr/hommage-jean-marie-charpentier/ ，请核对上面写的去世日期，并记录原文。
- 如果找到事务所官方发布、写明可使用的肖像，单独标注出来。

### 3.4 历史影像（镜1、镜4麦田和规划线稿用）

**收集：**
1. **2000–2005年前后长风片区的卫星或航拍影像。** 可以试 Google Earth 的历史影像（只能截图，放进“仅参考”目录），以及 USGS EarthExplorer（ https://earthexplorer.usgs.gov ）的 Landsat 影像（公有领域，但需要登录；不能登录就跳过并记下）。目的是看当年的地块是不是农田、内河和平台开工前是什么样。
2. **长风文化商务区早期规划图、方案效果图。** 搜索词：“长风文化商务区 规划”“长风商务区 控制性详细规划”“太原 长风 文化岛 规划方案”“Arte Charpentier Taiyuan”。只收官方或设计方发布的图，登记出处。全部放“仅参考”。
3. **今天的同角度影像。** 可以用 Google Earth 当前影像截同一个范围，用来做今昔对比的参考。

### 3.5 风格参考（决定整条片子的审美）

**用途：** 给制作者对齐镜头语言、配色和节奏。不进成片。

**已经确定的两条主参考**在 `视频/参考视频/`：参考1（区域与历史部分的画面和语气）、参考2（户内部分的运镜）。动手前先看完这两条，再找补充参考。补充参考要和这两条的气质一致：前半段是暗色地形、发光线条、纪录片感，后半段是奶白白模、连续运镜、白模长出材质。

**数量：** 可选，最多6条。两条主参考已经定了，补充参考只在你看到特别贴切的片段时才收，不必凑数。

**可以找的四类：**

| 类别 | 搜索词（中英文都试） | 看什么 |
| --- | --- | --- |
| 白模建筑动画 | architecture white model animation · massing model animation · 建筑白模动画 · 体块生成动画 | 浅色体块、柔和阴影、慢而稳的镜头 |
| 线稿转三维 | sketch to 3D architecture animation · line drawing to model transition · 手绘线稿 转 三维 动画 | 线条怎样立起来变成体块 |
| 城市生长或演变 | urban growth animation · city evolution timelapse 3D · 城市演变 动画 · 城市生长 动画 | 道路、楼群依次长出来的节奏 |
| 建筑科普讲述 | 建筑 科普 动画 抖音 · 建筑演变 视频号 · architecture explained animation | 旁白和画面怎么配合，每隔多久出一个“揭晓” |

**去哪找：** Vimeo、YouTube、B站、抖音、视频号、小红书，以及 Behance 上的建筑可视化作品。

**选的标准：**
- **要：** 浅色或白色为主的体块；阴影柔和；镜头慢、稳、连贯；转场有设计（线条、叠化、穿越）；画面干净，字少。
- **不要：** 写实渲染的地产广告片、炫光和粒子特效堆砌、快切、抖动的手持感、低帧率卡顿、画面里塞满文字的。

**每条登记：** 网址；值得看的时间段（例如 0:35–0:48）；一句话写清楚要借它的什么，例如“楼体从地面依次升起的节奏”“镜头穿过窗户进入室内的方式”；对应本片的镜号。截一张代表帧存进 `05_风格参考/`。

### 3.8 高程数据（开场镜1、第一二幕的三维地形）

**用途：** 开场的暗色三维地形，西山、汾河谷地要有起伏。

**来源：** AWS 开放高程瓦片（Terrarium 格式，公开下载，无需登录）。地址格式：

```text
https://s3.amazonaws.com/elevation-tiles-prod/terrarium/{z}/{x}/{y}.png
```

**步骤：**
1. 用第3.1节得到的外框，再向西扩0.15°，把西山包进来。
2. 用缩放级别 z=12 和 z=13，把覆盖外框的瓦片全部下载下来。瓦片编号的换算方法：x = floor((经度 + 180) / 360 × 2^z)，y = floor((1 − ln(tan(纬度) + 1/cos(纬度)) / π) / 2 × 2^z)，纬度用弧度。
3. 原样保存在 `10_高程数据/z12/` 和 `10_高程数据/z13/`，文件名用 `x_y.png`。
4. 登记表每个缩放级别登记一行即可，许可写“AWS Terrain Tiles（需署名数据来源）”。

### 3.9 材质与光照贴图（“一户两条线”里的白模长出材质）

**用途：** 户内从白模长出木地板、石材、布艺。风格参照参考2的0:12–0:15。

**来源：** 只用 CC0 资源，无需登录：
- Poly Haven（ https://polyhaven.com ）：材质（textures）和环境光照（HDRIs）。
- ambientCG（ https://ambientcg.com ）：材质。

**要找：**

| 类别 | 数量 | 要求 |
| --- | --- | --- |
| 浅色木地板 | 3 | 浅橡木、浅胡桃木一类，纹理细，不要深色 |
| 浅色石材 | 3 | 米白大理石、浅灰石材，纹理克制 |
| 布艺 | 3 | 米色、燕麦色的亚麻或绒布 |
| 墙面 | 2 | 白色或米白的细腻涂料、微水泥 |
| 室内环境光照 HDRI | 3 | 白天柔光一张、傍晚暖光一张、夜晚一张 |
| 室外环境光照 HDRI | 2 | 晴天和多云各一张，用于城市场景 |

**规格：** 材质下载2K分辨率，包含颜色、法线、粗糙度三张图；HDRI 下载2K的 .hdr。

**审美：** 整体是参考2那种奶白、浅木、浅灰的温和色调，不要深色、不要高饱和、不要做旧。

## 4. 登记表格式

`视频/素材/登记表.csv`，UTF-8 编码，第一行是表头，每个文件一行：

```text
文件路径,类别,对象,内容说明,对应镜号,来源网址,作者或机构,许可,可否用于成片,分辨率或时长,下载日期,备注
```

- **可否用于成片：** 只能填“可用”“仅参考”“待甲方授权”三种之一。

## 7. 汇报格式

写在 `视频/素材/汇报.md`，按下面五段写，每段用短句：

1. **完成情况：** 每一类收了多少，哪些没收到、为什么。
2. **地理数据检查结果：** 第3.1节第5步的五项检查，以及外框的四个经纬度数字。
3. **值得特别注意的素材：** 3–5条，说明为什么好、建议用在哪个镜头。
4. **发现的问题：** 例如名称和资料不一致、某个场馆在地图上没有轮廓、某张图的许可存疑。
5. **甲方需求清单：** 第3.6节的整理结果。
