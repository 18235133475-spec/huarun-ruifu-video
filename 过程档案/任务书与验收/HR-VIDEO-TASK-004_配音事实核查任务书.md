**出处的要求：**
- 优先用一手资料：政府或规划部门、设计方官网、场馆官网、权威媒体的原始报道。
- 每条出处都要有网址、标题、发布日期，以及一句不超过30字的原文摘录。
- 百科、自媒体、论坛只能作旁证，不能单独作为“证实”的依据。

**结论分四档：**

| 结论 | 含义 |
| --- | --- |
| 证实 | 至少一条一手出处支持 |
| 部分证实 | 大方向对，但细节有出入，例如年份、名称 |
| 无法证实 | 找不到可靠出处 |
| 有误 | 出处和配音说法相反 |

后三档都要给出建议改法。改法要短，适合配音口播。

## 3. B：视线方位计算

1. **定2号楼的位置。** 在甲方总平面上找2号楼，结合卫星图（`99_仅参考_不可用于成片/99_瑞府地块_卫星俯视_01.jpg`）和 OSM 道路，估出2号楼中心的经纬度。写清楚是怎么估的，估计误差多大。
2. **定2号楼的朝向。** 按总平面量出正面（西南面）的法线方位角：正北为0°，顺时针为正。导演的初步测量是：长边比正东西偏了约37°，正面朝向大约217°。
3. **算各个景的方位。** 从2号楼中心算到下面各点的方位角和距离：
   - 和园、谐园（`01_长风_公园.geojson` 里的 way/996055599、way/996055600）的形心，以及离2号楼最近的点；
   - 晋阳湖的形心，以及离2号楼最近的岸线点；
   - 五座场馆各自的形心；
   - 汾河离2号楼最近的水面点。
4. **判断“前面”和“身后”。** 正面法线左右90°以内算“前面”，以外算“身后”，离分界线20°以内的算“侧面”。逐项判断，和配音“前面是和园、谐园，再远是晋阳湖的方向；身后，是五大馆和汾河”对照。

   导演已经发现一个疑点：谐园在瑞府的西北方向，可能落在“侧面”甚至“身后”，请重点核实。
5. **出一张示意图。** 以2号楼为中心画出正面法线和各个景的方位线，标注角度和距离。用 matplotlib 本地生成即可。
