## 7. 自检标准（每包都跑，结果写进 meta.json）

| 项 | 标准 |
|---|---|
| 数值 | 足印、高度、面数等和源数据的偏差上限 |
| 格式 | glTF Validator 0 错误；只用色板材质，无贴图 |
| **合体自检** | 所有交付文件合在一起：包围盒落在约定范围内；同名部件互相对位（例：每个地面块的中心落在同名房间内）；坐标系一致 |
| **同机位对照** | 用第 3 节参考帧的相机参数出新旧对照图；不能看图时，用像素统计证明关键特征（例：横线节奏、颜色占比、边框是否空白） |
| 比例类要求 | 用数字证明（例：绿篱覆盖交界线 ≥ 70%；树种比例；铺装面积 ≤ 岛面积 35%） |

## 9. 验收方怎么验

1. 重跑全部自检。
2. 接入动画工程，用成片真实机位、光照、夜景着色器渲染新旧对照。
3. 看四点：风格是否一致；近景是否经得起看；有无穿模、闪烁、漂浮；是否和片中内容对得上。
4. 不通过的包出返工意见，只返工那一个包。
