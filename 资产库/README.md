# 资产库

这次项目沉淀下来的、下个项目可以直接拿来用的东西。

**文件怎么来的**：这里的数据和模型文件是工作目录里原文件的**硬链接**，不占额外磁盘，工作项目照常运行。原位置的资产更新后，运行下面这行重建（模板和说明文件是手写的，重建不会动它们。这个脚本只在原工作目录里能运行）：

```bash
bash 资产库/_build.sh
```

## 先知道这三条约定

1. **坐标系**：
   - 单位米；x 向东、y 向上、z 向南；
   - 原点在山西大剧院形心（UTM 49N，E0 = 634430.0964288089，N0 = 4185498.7249752167）；
   - 换算：x = E − E0，z = N0 − N。
   所有数据和模型都在这一个坐标系里，导入后不用平移。
2. **地面高度**：
   - 模型按地面 y = 0 建；
   - 动画工程里地面在 y = −1.5，接入时下沉 1.5m；
   - 文化岛平台顶面在 y = 4.5（平台高 6m）。
3. **材质名就是接口**：
   - 模型只带纯色材质，不带贴图；
   - 动画端按材质名（`wall`、`glass`、`office_glass`、`led`、`lawn`……）换成片中的配色和夜景着色器；
   - 色板与材质名对照表见 `视频/任务书/HR-VIDEO-TASK-007_全片模型精细化任务书.md` 第 4 节。

## 01 城市底座：太原长风（可复用，需署名）

覆盖：长风商务区、汾河两岸、晋阳湖、西山方向的远景。

| 子目录 | 内容 | 来源与许可 |
|---|---|---|
| 场景数据 | `buildings.json`（9,667 栋，[高度, 轮廓]）、`roads.json`、`water.json`、`parks.json`、`island.json`（文化岛轮廓）、`terrain.json` + `terrain_512.f32`（地形） | 3D-GloBFP（CC BY 4.0）、OSM（ODbL）、AWS Terrain Tiles |
| 远景城市 | 晋阳湖、河东老城方向的合并三角网（`far_city_*.bin`）、远景底图 | 同上 |
| 烘焙地面 | 区域地面底图（白天、夜景、二十年前三张）、树木分布 `trees.json` | OSM 分类 + Sentinel 植被 |
| 历史影像_Landsat | 2002 年和 2025 年长风片区影像及风格化版本 | USGS Landsat，公有领域 |
| 原始数据 | OSM GeoJSON、高程瓦片索引、地形高度图、带属性的建筑 GeoJSON | 同上 |

**怎么用**：在动画工程里由 `src/world.tsx`（城市、地形、水系、公园）和 `src/v2/data.tsx`（烘焙地面、远景、树）加载。新项目在长风片区范围内的，可以直接复用；范围外的，按 `视频/动画工程/tools/v2/build_*.py` 重新生成。

**署名**：
- 建筑数据：3D-GloBFP（Che et al., 2024）CC BY 4.0；
- 地图数据：© OpenStreetMap contributors；
- 植被：Contains modified Copernicus Sentinel data；
- 高程：AWS Terrain Tiles。

**怎么用**：接入写法见 `视频/动画工程/src/v2/map.tsx` 中 `refine` 一段：

## 06 动画引擎（代码在原位置，不复制）

`视频/动画工程/`：Remotion 4 + react-three-fiber + three.js。可复用的模块：

| 文件 | 可复用的东西 |
|---|---|
| `src/v2/timeline.ts` | 配音驱动的时间轴：镜头长度、字幕分条、关键词卡点 `kw()` 全部由配音时间自动算出 |
| `src/v2/map.tsx` | 区域地图场景 `MapScene`，以及一组着色器：城市亮窗 `skin`、写字楼幕墙 `officeMat`、夜景灯光秀 `showLit`、场馆泛光 `nightLit`、水面 `waterMat`、视线扇形 `fanMat`、内河引水 `innerMat` |
| `src/v2/theme.tsx` | 配色 `P`（日）、`N`（夜）、地标色 `LANDMARK`；标注框 `Callout`（统一版式规则）、楼栋标签、各类标题组件 |
| `src/v2/transitions.tsx` | 转场：滑入、滑出、翻页、剪纸斑块；字幕组件 `Captions` |
| `src/v2/geo.tsx` | 坐标与相机：`CamFrom`、`makeCamera`、`lerpCam`、`toScreen`（场景点 → 画面像素） |
| `src/v2/unit.tsx` + `src/unitdress.ts` | 户型剖切沙盘、讲到哪里亮哪里的聚焦着色 `patchFocus`、圆角软装生成、剪影小人 |
| `src/v2/open.tsx` | 黑底书名标题卡 `BookTitle`（片头片尾） |
| `src/v2/sunshot.tsx` | 日照对比图表镜头 |
| `src/world.tsx` | 城市、地形、水系、公园、五大馆、瑞府楼栋的加载与生长动画 |

渲染开关：`--props='{"refine":true}'`（精细化模型）、`"refineUnit":true`（精细版户型）、`"noCaps":true`（去字幕，做文章动图用）。详见 [接手指南](../项目沉淀/05_接手指南.md)。
