# 一栋楼，为太原转了个身

华润·太原瑞府 2 号楼 355㎡ 的一次完整内容制作：

- 一篇公众号软文；
- 一部 7 分 18 秒、真人配音的三维动画解说片；
- 一套配合文章的动图。

本仓库是项目交付后**整理过的沉淀**：复盘与数据、可复用资产、动画工程源码、成果，以及精选的过程档案。原始工作目录（约 18 GB，含甲方资料、渲染中间文件、全部历史版本）保留在本机，不在仓库里。

## 有意没放进仓库的

| 内容 | 原因 |
|---|---|
| 甲方效果图、样板间照片、总平面、内部说辞，以及由甲方图纸派生的瑞府楼栋、小区园林、户型模型 | 甲方资料，不外传 |
| 参考文章原文、建筑师官网照片、参考视频、谷歌地球截图 | 第三方版权 |
| 用户本人配音、配乐文件 | 个人声音；配乐许可不允许单独再分发 |
| 成片（约 280 MB）、历史版本、渲染中间文件 | 体积大，可在本机重新生成 |

所以本仓库里的动画工程**不能独立渲染出完整成片**，缺甲方衍生资产和配音；在原工作机上可以完整运行。详见 [项目沉淀/08 GitHub 打包说明](项目沉淀/08_GitHub打包说明.md)。

## 路径约定

项目沉淀里的文档以本机工作目录 `华润瑞府/` 为基准描述路径（例如 `视频/动画工程/…`）。仓库内的对应位置：

| 工作目录 | 仓库 |
|---|---|
| `华润瑞府/项目沉淀/` | `项目沉淀/` |
| `华润瑞府/资产库/` | `资产库/` |
| `华润瑞府/视频/动画工程/src`、`tools` | `动画工程/src`、`tools` |
| `华润瑞府/视频/任务书/`、`视频/HR-VIDEO-*.md` | `过程档案/` |

仓库由工作目录里的 [`项目沉淀/仓库同步.py`](项目沉淀/仓库同步.py) 生成，更新时重跑它再提交。
