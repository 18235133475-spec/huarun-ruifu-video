# 目录地图

项目根目录：`华润瑞府/`，共约 18 GB，其中 `视频/` 占 18 GB（大头是渲染输出和依赖包）。

状态说明：
- **活跃**：后续开发会用到；
- **归档**：历史过程，留作追溯；
- **保密**：甲方资料或甲方衍生，只在本机；
- **可清理**：可以重新生成，空间紧张时可删。

哪些内容收进了 GitHub 仓库，见 [GitHub 打包说明](08_GitHub打包说明.md)。
