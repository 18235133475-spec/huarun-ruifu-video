# 接手指南

给下一个接手的人或智能体：用最短时间看懂这个项目、把工程跑起来、安全地改一个镜头。

## 一、先读这五份（约 15 分钟）

1. [项目总览](01_项目总览.md)：做了什么，现在交付到哪一步。
2. [风格与规则手册](06_风格与规则手册.md)：用户确认过的所有规则，**改任何画面和文字之前必读**。
3. [目录地图](04_目录地图.md)：每个文件夹是什么、能不能动。
4. [合规与发布前检查](07_合规与发布前检查.md)：保密边界和发布前的待办。
5. [资产库](../资产库/README.md)：坐标系约定和可复用资产。

## 二、硬性规则

- **甲方资料不外传**：`视频/甲方提资/`、`视频/动画工程/public/client/`，以及由甲方图纸派生的数据（瑞府楼栋、小区园林、户型）只在本机用。如果你的看图工具会把图片上传到外部服务器，不要用它打开这些图片，派生数据用程序按数值读取。
- **同步目录只读**：项目镜像根目录下 `sources/` 里的文件只读，不改、不移、不删（见镜像根目录 `AGENTS.md`）。
- **不移动成片和替换片段**：用户在本地剪辑软件里可能引用了 `视频/` 根目录的成片和 `替换片段_2026-10-25/`。
- **删除前先问**：删除用户的文件、清理磁盘之前，先征得用户同意。
- **配音不动**：最终成片的声音是用户本人的原始录音（`素材/06_音乐/人声配音_2026-10-24/用户完整版原始_2026-10-25.wav`），只做整体平移，不做剪辑和响度调整。

## 三、把工程跑起来

工程在 `视频/动画工程/`：Remotion 4 + react-three-fiber + three.js。Node 依赖已装好；如被清理，运行 `npm install`。

```bash
cd 视频/动画工程
npx remotion studio src/index.ts
```

Studio 里选 `Film3`（全片）。常用的还有：
- `UnitGrid`：户型全图，调试用；
- `Thumbs`：缩略图；
- `Film3Alt`：日照段的另一版。

### 渲染

先打包，再渲染。打包目录 `out/v2/bundleNN`，用完删掉旧的。

```bash
npx remotion bundle src/index.ts --out-dir=out/v2/bundle99
npx remotion render out/v2/bundle99 Film3 out/v2/full_raw.mp4 --gl=angle --concurrency=4 --port=3124 --props='{"refine":true}'
```

- 整片约 17 分钟。
- 只渲一段：加 `--frames=起-止`。
- 单帧：`npx remotion still ... --frame=N --port=3125`。
- `--gl=angle` 不能省（三维场景需要）；两个渲染同时跑时，端口要错开。

### 渲染开关（`--props`）

| 开关 | 作用 | 最终成片 |
|---|---|---|
| `"refine": true` | 换上全片精细化模型（refine_v1） | 开 |
| `"refineUnit": true` | 户型换成精细版（验收结论：不采用） | 关 |
| `"noCaps": true` | 去掉字幕（做文章动图用） | 关 |
| 不传任何开关 | v9 原样 | — |

### 合成声音

用户的录音比时间轴晚约 85ms，整体提前后铺上（v10、v11 都这样做）：

```bash
ffmpeg -i out/v2/full_raw.mp4 -i ../素材/06_音乐/人声配音_2026-10-24/用户完整版原始_2026-10-25.wav -map 0:v -map 1:a -c:v copy -af "atrim=start=0.085,asetpts=PTS-STARTPTS,apad" -t 437.845 -ar 48000 -c:a aac -b:a 256k -movflags +faststart 成片.mp4
```

只要时间轴不变，就可以直接这样合成。时间轴变了（加减镜头、改镜头长度），录音要按同样的位置剪，参考 10/25 去章节卡时的做法：剪口放在下一句人声开始之前，做 0.3 秒交叉淡化。

## 五、常见改动怎么做

- **改一句字幕的写法**：改 `src/script4.json` 对应镜头的 `segs`。配音不变，时间不用动。
- **改画面里的标题、标注**：在对应镜头文件里改；标注框用 `Callout` 的 `band` 版式，遵守规则手册第三节。
- **镜头里多停一会儿**：改 `timeline.ts` 的 `EXTRA`。时间轴会变，配音要相应处理（见上文）。
- **换模型**：先查[资产库](../资产库/README.md)；新模型按[任务书模板](../资产库/05_模板/任务书模板.md)外包，按[验收意见模板](../资产库/05_模板/验收意见模板.md)验收；接入时加开关，旧版本保持可复现。
- **出替换片段**：用户在本地剪辑时，只渲改动的帧段，文件名写清时间码和内容。

## 六、容易踩的坑

| 坑 | 说明 |
|---|---|
| 磁盘写满 | 渲染中间文件很大，开工前确认剩余空间 ≥ 20 GB；10/24 曾写满中断 |
| 多材质 GLB 的网格名 | three.js 加载后，多材质节点会变成一个组，子网格名带 `_1`、`_2` 后缀；按名字匹配时要考虑 |
| 地面共面闪烁 | 模型地面和底图同高会闪；精细化地面统一抬高 0.03–0.25m |
| 旧白模和新模型重叠 | 新模型替换某个位置时，要把城市白模里同位置的旧体块扣掉（`city_near_ids.json` 机制） |
| 微信传文件 | 用“视频”方式发会被压缩（画面减半、声音约 72kbps），一律用“文件”方式 |
| 互相关测偏移 | 声音对齐用人声频段（300–3000Hz）包络互相关，不要用整段波形（配乐会主导结果） |
