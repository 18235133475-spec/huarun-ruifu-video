# GitHub 打包说明

## 原则

仓库放的是**复盘整理过的沉淀**，不是工作目录的快照。工作目录（约 18 GB）留在本机，是唯一的源头；仓库由同步脚本从工作目录挑选生成。

- **本机位置**：`华润瑞府/_GitHub仓库/`
- **远程**：GitHub 私有仓库（账号 `18235133475-spec`）

## 仓库收什么（约 240 个文件，约 175 MB）

| 仓库目录 | 内容 | 来自工作目录 |
|---|---|---|
| `README.md`、`AGENTS.md` | 仓库入口、给 AI 智能体的说明 | `项目沉淀/仓库模板/` |
| `项目沉淀/` | 总览、数据统计、复盘、目录地图、接手指南、风格规则、合规检查、本说明、统计原始数据 | `项目沉淀/` |
| `资产库/` | 城市底座、地标与场景模型、工具脚本、模板（不含 03 甲方衍生） | `资产库/` |
| `动画工程/` | 源码 `src/`、工具脚本 `tools/`、依赖清单 | `视频/动画工程/` |
| `成果/` | 文章正文（由 Word 转出，不含图片）、配音稿、文章动图 12 张 | `视频/文章配图/`、配音稿 |
| `过程档案/` | 视频方案与审查意见、任务书与验收意见（只收文档）、定稿风格样帧、写作阶段分析与原创概念图 | `视频/`、`视频/任务书/`、`风格样帧/第三版/`、`文章拆解/`、`概念配图/` |

## 不收什么，为什么

| 内容 | 原因 |
|---|---|
| 甲方效果图、样板间照片、总平面、内部说辞 | 甲方资料，不外传。私有仓库也是交给了外部服务 |
| 甲方衍生数据：瑞府楼栋、小区园林、户型模型与平面数据 | 由甲方图纸派生，视同甲方资料 |
| 参考软文原文与 PDF、建筑师官网照片、参考视频、谷歌地球截图、动图 g04 | 第三方版权 |
| 用户本人配音、配乐 | 个人声音；Pixabay 许可不允许单独再分发音乐文件 |
| 成片与历史版本、修改预览、渲染输出 | 体积大（成片单个约 280 MB），可在本机重新生成 |
| 写作阶段的初稿、早期测试视频、AI 生成试验、各轮中间样帧和对照图 | 过程中间产物，结论已写进复盘和规则手册 |

所以仓库里的动画工程不能独立渲染出完整成片。在原工作机上不受影响。

## 怎么更新

改动先改工作目录（文档、资产、源码），然后：

```bash
cd 华润瑞府
python3 项目沉淀/仓库同步.py      # 重新生成 _GitHub仓库/
cd _GitHub仓库 && git add -A && git commit -m "说明改了什么" && git push
```

同步脚本的规则：

- 每次先清空仓库内容，保证删掉的文件不残留；`.git` 保留；
- 文件用硬链接，不占额外磁盘；
- 新增一类要进仓库的内容，在脚本里加一行；
- 仓库专用的说明文件改 `项目沉淀/仓库模板/`。

## 成片放哪

成片不进 Git。发布后：

- 在 `成果/README.md` 补上链接；
- 或者作为 GitHub Release 的附件上传（单文件上限 2 GB）。上传前先处理完[合规](07_合规与发布前检查.md)第一节的待办。
