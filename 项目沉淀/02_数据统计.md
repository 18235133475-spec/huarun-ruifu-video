## 五、Token 与等效成本

### Claude Code（claude-opus-5-5）

按官方价目：输入 $4、输出 $20、缓存写入（5 分钟 $5、1 小时 $8）、缓存读取 $0.20，均为每百万 Token。按消息 ID 去重（分叉会话会复制前缀），子智能体会话计入。

| 项目 | Token | 成本 |
|---|---|---|
| 未缓存输入 | 0.5 万 | $0.02 |
| 输出 | 304 万 | $61.1 |
| 缓存写入 | 2,459 万 | $192.7 |
| 缓存读取 | 10.97 亿 | $221.3 |
| **合计** | | **约 $474**（主会话 $439，子智能体 $35） |

| 日期 | 10/16 | 10/17 | 10/19 | 10/20 | 10/21 | 10/22 | 10/23 | 10/24 | 10/25 |
|---|---|---|---|---|---|---|---|---|---|
| 成本 | $4 | $14 | $4 | $40 | $61 | $44 | $146 | $104 | $56 |

**成本结构的含义**：87% 花在缓存读写上，模型真正“写”出来的内容只占 13%。长会话里堆积了大量图片和大文件，每一轮都要把整个上下文再读一遍。改进办法见 [复盘](03_复盘.md) 第三节。

### Codex（gpt-6.1-sol）

合计 1.96 亿 Token，其中缓存命中 1.87 亿、输出 96 万（含推理 35 万）。逐会话明细见 [数据/codex_统计.json](数据/codex_统计.json)。

不折算美元：这个模型的官方价格我没法可靠查证，而且它走的是你的 ChatGPT 套餐额度，不按 API 单独计费。如果要折算，按“未缓存输入 760 万 + 缓存输入 1.87 亿 + 输出 96 万”乘以当期价目即可。

### ChatGPT 外部任务

TASK-006、TASK-007、007b 在 ChatGPT 上执行，本机没有会话记录，Token 无法统计。

## 六、统计口径与局限

- Claude Code 数据来自 `~/.claude/projects/<本项目>/` 下的会话记录；Codex 数据来自 `~/.codex/sessions/`。
- 10/22 的“清理磁盘”Codex 会话与项目无关，未计入。
- 用户需求条数按消息前 120 字去重，跨会话重复的只算一次。
- 渲染次数按命令统计，批量循环里的单帧没有逐张计数；以输出目录现存文件为准。
- 统计脚本：[数据/统计脚本_claude_code.py](数据/统计脚本_claude_code.py)，可重跑。
