# 项目总览

## 一句话

为华润·太原瑞府 2 号楼 355㎡ 写一篇公众号软文《一栋楼，为太原转了个身》，再把它做成一部 7 分 18 秒、用户本人配音的三维动画解说片，并给文章配上片中动图。

## 片子结构

| 章节 | 镜头 | 讲什么 |
|---|---|---|
| 开场 | O1–O9 | 沿汾河的楼都朝南，最北侧两栋转向西南；转身后看见的园、湖、河、馆、城；日照对比；收官之作；四个理由 |
| 一、位置 | CP、P1–P5 | 长风的来历：二十年前的田地、造岛引水、抬起的平台、夏邦杰，望向的就是这里 |
| 二、楼栋 | CQ、Q1–Q3 | 不同楼层的视野；每层只有一套；两梯一户和专属玄关厅 |
| 三、户型 | CR、R1–R10 | 一纵一横：从和园到汾河的纵轴，从玄关分开“聚”和“私”的横轴 |
| 四、耐心 | CS、S1–S2 | 每加推一次就开新样板间；规划调整，户数少了 104 户 |
| 五、天花板 | CT、T1–T3 | 四个理由合在一起；长风夜景；“推窗是山水，回身是家人” |

逐镜头帧位见 [接手指南](05_接手指南.md) 第七节。

## 技术路线

```
用户主稿 → 配音稿 → 动态分镜（M1）
   ↓
开放数据（3D-GloBFP 建筑、OSM 道路水系、AWS 地形、Sentinel 植被）→ 城市三维底座
公开资料 + 外包建模 → 五大馆、三座桥、和园、长风商务区、近景城市、文化岛、滨河道路
甲方图纸（仅本机）→ 瑞府楼栋、小区园林、户型剖切沙盘
   ↓
Remotion + react-three-fiber 自绘统一风格动画（时间轴由配音驱动）
   ↓
逐段预览 → 用户确认 → 锁定 → 合成全片 → 全片审查
   ↓
用户本人录音 → 自动对齐切分 → v9 人声版 → 模型精细化（v10）→ 去来源小字（v11）
   ↓
衍生：文章配动图
```
